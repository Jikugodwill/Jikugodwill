# Contact button assets

Self-contained SVG buttons for the profile README. Each button is wrapped in an HTML link in the root README; the SVG files do not contain scripts or external resources.

- LinkedIn glyph: [Devicon](https://github.com/devicons/devicon/blob/master/icons/linkedin/linkedin-plain.svg), MIT license reproduced below.
- X glyph: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/x.svg), CC0.
- KwadRise glyph: the original mark from the [KwadRise website logo](https://www.kwadrise.com/_next/static/media/logo.0ksk1~6j8ir62.svg), preserving its purple fill. This extracts the mark for the compact button; the brand wordmark remains unchanged at its source.
- Email envelope and button framing: custom SVG geometry.
